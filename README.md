# henge
You can use Henge to track your garden or a small farm. Henge is a Agricultural calendar showing you when Moon and Season Dates. Using data from a central database called Botanica hosted on Parse you can use Henge to estimate the quanity of seeds needed and possible harvests based on row length or acreage. Using the Botanica data you can create Crops on a local database and track watering, soil amendments, harvests and store notes.
